## SISTEMA DE ACTUALIZACION (v2.9.63+)

### Flujo de actualización online:
1. Usuario va a Configuracion > Actualizar Sistema > Buscar actualizaciones
2. GET /api/check-version → consulta GitHub Releases API con token
3. Fallback a public/versions.json si no hay internet
4. Muestra lista de versiones con changelogs, badges, fechas
5. POST /api/update → SSE con progreso en tiempo real:
   - Paso 1: Verificar prerequisitos
   - Paso 2: Respaldo automático (BD + uploads + logo)
   - Paso 3: Descargar ZIP desde GitHub (redirect: manual para privados)
   - Paso 4: Extraer ZIP
   - Paso 5: Copiar archivos nuevos (lista UPDATE_ITEMS en update/route.ts)
   - Paso 6: Limpiar temporales
   - Paso 7: Migrar BD (prisma generate + prisma db push)
   - Paso 8: REBUILD automático (script .bat detached que ejecuta npm run build + reinicio)
   - Paso 9: Completado + auto-recarga de pagina a los 15 seg

## SISTEMA DE VERSION DINAMICA (v2.9.66)

### Problema resuelto:
- Antes: version "v2.9.56" estaba HARDCODEADA en 11 lugares del codigo
- Al actualizar, los archivos se copiaban pero el build viejo seguia mostrando "v2.9.56"

### Solucion:
- src/lib/app-version.ts → modulo server-side, lee package.json con fs
- src/lib/app-version-client.ts → modulo client-side, carga desde /api/app-version
- src/app/api/app-version/route.ts → endpoint que retorna version de package.json
- TODOS los componentes ahora usan version dinamica:
  - layout.tsx (titulo de pagina)
  - page.tsx (header, nav, footer - 3 lugares)
  - app-nav.tsx (sidebar)
  - login-screen.tsx (2 lugares)

  - catalog/route.ts (catalogo productos)
