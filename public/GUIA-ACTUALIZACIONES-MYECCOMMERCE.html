Actualizaciones del Sistema
Guia completa paso a paso para mantener su sistema MyeCommerce POS siempre actualizado, con metodos online automaticos y local manual.
Version 2.9.58+
Introduccion
Como funcionan las actualizaciones
MyeCommerce POS tiene un sistema de actualizaciones integrado que le permite mantener su software siempre al dia con las ultimas mejoras, correcciones de errores y nuevas funciones. Existen dos metodos para actualizar: uno automatico (online) y uno manual (local). Ambos metodos son seguros y crean un respaldo de su base de datos antes de realizar cualquier cambio.
Lo que se preserva siempre
Independientemente del metodo que elija, la actualizacion NUNCA borra sus datos. Se preservan: la base de datos (prisma/dev.db), las imagenes de productos (data/uploads/), los respaldos anteriores (BACKUPS/), y el archivo caddy.exe si lo usa. Solo se reemplazan los archivos del programa (src/, public/, scripts .bat).

Metodo 1
Actualizacion Online (Automatica)
Este es el metodo recomendado. Todo se hace desde dentro de la aplicacion, sin necesidad de descargar archivos ni usar programas externos. La app se conecta a GitHub, descarga la nueva version, la instala y migra la base de datos automaticamente. Solo necesita hacer click en dos botones y esperar.
Requisitos previos
La PC servidor debe tener conexion a internet activa. No necesita descargar nada manualmente. Asegurese de que no hay ventas en proceso antes de iniciar la actualizacion. La actualizacion tarda entre 2 y 5 minutos dependiendo de la velocidad de internet.

2. Desplaze hacia abajo hasta encontrar la seccion "Soporte".

Metodo 2
Actualizacion Local (Manual)
Use este metodo si la PC servidor no tiene internet o si prefiere tener control manual sobre el proceso. Necesita descargar un archivo ZIP desde otra PC con internet, copiarlo a la PC servidor, y ejecutar un script de actualizacion.
Paso 1: Descargar el archivo ZIP
Desde una PC con internet:
1. Abra MyeCommerce en cualquier navegador
2. Vaya a Configuracion > Soporte
3. Click en "Buscar Actualizaciones"
4. Click en el boton: "Descargar v2.9.90 (ZIP)"

Nombre del archivo que se descarga:
MyeCommerce-v2.9.20-v2.9.90.zip
Formato: Archivo ZIP (carpeta comprimida)
Tamano aproximado: 15 a 25 MB
Paso 2: Copiar el archivo a la PC servidor
Copie el archivo ZIP a la carpeta de MyeCommerce:

Carpeta del sistema:
C:\MyeCommerce\

Destino:
C:\MyeCommerce\MyeCommerce-v2.9.20-v2.9.90.zip

Puede usar memoria USB, compartido de red, etc. Lo importante es que el ZIP quede dentro de la carpeta MyeCommerce, al mismo nivel que los demas archivos.

Informacion Importante
Que se hace con sus datos
Ambos metodos crean un respaldo automatico antes de hacer cualquier cambio. Este respaldo se guarda en una carpeta con la fecha y version.
ElementoAccionPor que
Base de datos (dev.db)SE PRESERVATiene sus productos, ventas, clientes
Imagenes (data/uploads/)SE PRESERVAArchivos unicos que no vienen en el ZIP
Respaldos (BACKUPS/)SE PRESERVASus respaldos quedan intactos
Codigo fuente (src/)SE REEMPLAZAEs el codigo actualizado
Scripts (.bat, .vbs)SE REEMPLAZAPueden tener mejoras
package.jsonSE REEMPLAZANueva version y dependencias
Schema BD (schema.prisma)SE REEMPLAZANuevas tablas o campos
caddy.exeSE PRESERVAArchivo binario externo
Donde queda el respaldo?
Carpeta de respaldo (ejemplo):
C:\MyeCommerce\BACKUP_AUTO_v2.9.58_2026-08-17_1430\

Dentro encontrara copias de: dev.db, schema.prisma y uploads/.
Si algo sale mal, restaure copiando estos archivos a sus posiciones originales.
Solucion de Problemas
Que hacer si algo falla
"Error al descargar: HTTP 404"
La version no existe en GitHub. Verifique el numero de version. Puede que la etiqueta tenga formato diferente. Vuelva a buscar actualizaciones.
"database is locked"
Hay otro proceso usando la base de datos. Cierre la app completamente (DETENER-TODO.bat) antes de actualizar. Asegurese de que no quedan ventanas del navegador abiertas.
La actualizacion quedo a la mitad
No se preocupe. El respaldo automatico esta seguro. Los archivos viejos estan en BACKUP_AUTO. Puede restaurar copiando los archivos del respaldo, o intentar la actualizacion de nuevo.
Despues de actualizar, la app no carga
Ejecute INSTALAR.bat para reinstalar dependencias. Luego INICIAR-TODO-OCULTO.vbs. Si persiste, restaure dev.db desde el respaldo.
