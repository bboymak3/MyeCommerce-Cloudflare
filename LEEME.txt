1. REQUISITOS
=============================================================

- Windows 10 o superior (64 bits)
- Node.js 20 LTS instalado
  Descarga: https://nodejs.org
  (Elija la opcion LTS, la que dice "Recommended for Most Users")
- Conexion a internet SOLO para la primera instalacion
  Despues de instalar, el sistema funciona 100% sin internet
- Impresora termica conectada por USB (opcional, para imprimir tickets)


=============================================================
2. INSTALACION EN UNA PC NUEVA (paso a paso)
=============================================================

PASO 1 - Instalar Node.js
--------------------------
  a) Abra el navegador y vaya a: https://nodejs.org
  b) Descargue la version 20.x LTS
  c) Ejecute el instalador descargado
  d) Siga los pasos por defecto (Next, Next, Install, Finish)
  e) Reinicie la PC si se lo pide

PASO 2 - Descargar MyeCommerce POS
-----------------------------------
  a) Descargue el ZIP desde el repositorio:
     https://github.com/csglider/MyeCommerce-v2.9.20
     (boton verde "Code" > "Download ZIP")
     O descargue la ultima version desde la carpeta zip/
  b) Descomprimalo en una carpeta fija, por ejemplo:
     C:\MyeCommercePOS
  c) IMPORTANTE: No use carpetas con espacios ni caracteres especiales
     MAL:  C:\Mis Documentos\MyeCommerce
     BIEN: C:\MyeCommercePOS

PASO 3 - Ejecutar la instalacion
-------------------------------
  a) Abra la carpeta donde descomprimio el sistema
  b) Click DERECHO sobre INSTALAR.bat
  c) Seleccione "Ejecutar como administrador"
  d) Espere a que termine (tarda 3-5 minutos la primera vez)
  e) El instalador hace todo automaticamente:
     - Instala dependencias del sistema (npm install)
     - Crea la base de datos (npx prisma db push)
     - Compila para produccion (npm run build)

PASO 4 - Crear usuario administrador
------------------------------------
  a) Doble clic en CREAR-ADMIN.bat
  b) Siga las instrucciones (usuario y clave)

PASO 5 - Iniciar el sistema
---------------------------
  a) Doble clic en INICIAR-MYECCOMMERCE.bat
  b) O use INICIAR-TODO.bat para iniciar con Caddy + impresora
  c) Se abrira el navegador automaticamente en:
     - https://myecommerce.ve (con Caddy activo)
     - http://localhost:3000 (sin Caddy)


=============================================================
3. QUE INSTALA CADA ARCHIVO
=============================================================

ARCHIVOS PRINCIPALES (en la raiz del sistema):

INSTALAR.bat
  - Instala las dependencias (npm install)
  - Crea/actualiza la base de datos (prisma db push)
  - Compila el proyecto (npm run build)
  - Ejecutar como Administrador.
  - Ejecutar SOLO la primera vez o al actualizar version.

INSTALAR-LIMPIO.vbs
  - Instalacion completa desde cero.
  - Hace TODO: dependencias, base de datos, printer-agent, caddy,
    compilacion, acceso directo.
  - Ejecutar como Administrador.

INICIAR-TODO-OCULTO.vbs
  - Inicia los 3 servicios SIN abrir ventanas CMD.
  - Inicia: Printer-Agent + Caddy + Next.js
  - Espera a que Next.js este listo y abre el navegador.

INICIAR-TODO.bat
  - Igual que el VBS pero con ventanas CMD visibles.
  - Usar SOLO para ver errores o hacer debug.

INICIAR-MYECCOMMERCE.bat
  - Inicia solo Next.js (sin Caddy ni printer-agent).
  - Ideal para uso rapido sin extras.

DETENER-TODO.bat
  - Detiene todos los servicios.
  - Usar antes de apagar la PC o reinstalar.

CREAR-ADMIN.bat
  - Crea el primer usuario administrador.
  - Ejecutar despues de INSTALAR.bat.

GENERAR-LICENCIA.bat
  - Genera una clave de licencia para el sistema.
  - Requiere plan BASICA+ para funciones avanzadas.

RESPALDAR-BD.bat
  - Crea un ZIP con la base de datos completa.
  - Se guarda en la carpeta "respaldos".

LEEME.txt
  - Esta guia de instalacion y referencia.

5. INICIAR EL SISTEMA
=============================================================

FORMA NORMAL (recomendada):
  - Doble clic en INICIAR-TODO-OCULTO.vbs
  - No abre ventanas CMD, inicia todo en segundo plano
  - Abre el navegador automaticamente

FORMA RAPIDA (sin Caddy ni impresora):
  - Doble clic en INICIAR-MYECCOMMERCE.bat
  - Inicia solo Next.js en el puerto 3000

FORMA DEBUG (para ver errores):
  - Doble clic en INICIAR-TODO.bat
  - Abre ventanas CMD donde puede ver si hay errores

QUE SE INICIA:
  1. Printer-Agent en puerto 9100 (impresion termica)
  2. Caddy en puerto 443 HTTPS (proxy: myecommerce.ve -> localhost:3000)
  3. Next.js en puerto 3000 (la aplicacion web)

URLs DE ACCESO:
  - https://myecommerce.ve    (si Caddy esta activo, requiere admin)
  - http://localhost:3000     (alternativa sin HTTPS)

6. DETENER EL SISTEMA
=============================================================

  - Doble clic en DETENER-TODO.bat
  - O simplemente apague la PC (se detienen solos)

7. IMPRESORA TERMICA (Printer-Agent)
=============================================================

QUE ES:
  El Printer-Agent es un pequeno servidor que recibe comandos
  de impresion desde el navegador y los envia directamente a
  la impresora termica por USB.

COMO VERIFICAR QUE FUNCIONA:
  1. Inicie el sistema (doble clic en el acceso directo)
  2. Abra el navegador y vaya a: http://localhost:9100/status
  3. Debe mostrar: {"status":"online", ...}
  4. Si no muestra nada, el agente no esta corriendo

CONFIGURAR EN LA APP:
  1. Abra https://myecommerce.ve (o localhost:3000)
  2. Vaya a Configuracion (el icono de engranaje)
  3. Busque la seccion "Agente de Impresion ESC/POS"
  4. Active el toggle "Usar agente ESC/POS"
  5. La direccion debe ser: http://localhost:9100
  6. Haga clic en "Probar conexion"
  7. Debe aparecer verde: "Agente conectado"

IMPRESORAS COMPATIBLES:
  - Cualquier impresora termica POS de 58mm o 80mm
  - Las que usan chip CH340, CP210, Prolific
  - Marcas: Xprinter, MTP, Goojprt, POS-58, POS-80, etc.


=============================================================
8. DOMINIO LOCAL (Caddy)
=============================================================

QUE HACE:
  Caddy es un servidor web que actua como proxy.
  Hace que en vez de escribir http://localhost:3000
  pueda escribir simplemente https://myecommerce.ve
  con certificado SSL valido (candado verde en el navegador).

REQUISITOS:
  - Ejecutar como Administrador (para usar el puerto 443)
  - El instalador INSTALAR-LIMPIO.vbs lo configura automaticamente

SI CADDY NO SE DESCARGO:
  1. Vaya a: https://caddyserver.com/download
  2. Descargue la version Windows AMD64
  3. Copie caddy.exe a la carpeta caddy/ del sistema

SI NO TIENE PERMISOS DE ADMIN:
  - El sistema seguira funcionando en http://localhost:3000
  - Caddy no podra usar el puerto 80 sin administrador


=============================================================
9. ACCESO DESDE TELEFONOS Y TABLETS
=============================================================

REQUISITOS:
  - El servidor PC y el telefono deben estar en la misma red WiFi

PASOS:
  1. Necesita conocer la IP del servidor PC
     - Abra CMD en el servidor y escriba: ipconfig
     - Busque la direccion IPv4, ej: 192.168.1.100
  2. En el telefono/tablet abra el navegador:
     http://192.168.1.100:3000
  3. Debe aparecer la pantalla de login de MyeCommerce

NOTA: El dominio myecommerce.ve solo funciona en la PC servidor.
Desde el telefono use la IP directamente.


=============================================================
10. INICIO AUTOMATICO CON WINDOWS
=============================================================

Para que el sistema inicie automaticamente al encender la PC:

  1. Presione en el teclado: Windows + R
  2. Escriba: shell:startup
  3. Presione Enter (se abre una carpeta)
  4. En esa carpeta, cree un acceso directo que apunte a:
     INICIAR-TODO-OCULTO.vbs
     (ubicado en la carpeta del sistema)
  5. Listo, cada vez que encienda la PC el sistema iniciara solo

Tambien puede usar CREAR-INICIO-AUTOMATICO.bat que lo hace
automaticamente.


=============================================================
11. RESPALDAR BASE DE DATOS
=============================================================

  1. Doble clic en RESPALDAR-BD.bat
  2. Se crea un archivo ZIP en la carpeta "respaldos"
  3. El ZIP contiene la base de datos completa:
     - Productos, categorias, proveedores y compras
     - Clientes con limites de credito
     - Ventas, devoluciones y cierres de caja
     - Usuarios, roles, configuracion y licencia

PARA RESTAURAR:
  1. Detenga el sistema (DETENER-TODO.bat)
  2. Descomprima el ZIP del respaldo
  3. Copie dev.db a la carpeta prisma/ (reemplaza la actual)
  4. Inicie el sistema normalmente

12. SOLUCION DE PROBLEMAS
=============================================================

PROBLEMA: El sistema no inicia / "Node.js no esta instalado"
SOLUCION: Instale Node.js 20 LTS desde https://nodejs.org
         Reinicie la PC despues de instalar.

PROBLEMA: No abre https://myecommerce.ve
SOLUCION: Use http://localhost:3000 mientras tanto.
         Ejecute INSTALAR-LIMPIO.vbs como Administrador.

PROBLEMA: La impresora no imprime
SOLUCION: 1. Vaya a http://localhost:9100/status en el navegador
         2. Si no responde, el agente no esta corriendo
         3. Abra CMD y ejecute:
            cd printer-agent && node agent.js
         4. Verifique que la impresora este conectada por USB
         5. En Configuracion de la app, pruebe la conexion

PROBLEMA: Desde el telefono no puedo acceder
SOLUCION: 1. Verifique que telefono y PC estan en la misma WiFi
         2. Use la IP del PC, no myecommerce.ve
         3. Ejemplo: http://192.168.1.100:3000

PROBLEMA: Quiero reinstalar todo desde cero
SOLUCION: 1. Haga un respaldo (RESPALDAR-BD.bat)
         2. Borre la carpeta .next y node_modules
         3. Ejecute INSTALAR.bat como Administrador

PROBLEMA: Error al actualizar de una version anterior
SOLUCION: 1. Respaldar base de datos (RESPALDAR-BD.bat)
         2. Reemplazar todos los archivos por la nueva version
         3. Ejecutar INSTALAR.bat (actualiza dependencias + BD)
         4. La base de datos se migra automaticamente

14. METODOS DE PAGO SOPORTADOS
=============================================================

METODO                | MONEDA  | DESCRIPCION
----------------------|---------|------------------------------------------
Efectivo (Bs)         | Bs      | Pago en efectivo bolivares
Efectivo ($)          | USD     | Pago en efectivo dolares (billetes)
Pago Movil            | Bs      | Transferencia via Pago Movil
Transferencia         | Bs      | Transferencia bancaria
Punto de Venta        | Bs      | Terminal POS fisico (debito/credito)
Zelle                 | USD     | Transferencia Zelle (dolares)
USDT                  | USD     | Tether / criptomonedas
Cheque                | Bs      | Pago con cheque
Cashea                | Bs/USD  | Buy Now Pay Later (compra ahora, paga despues)
Credito               | Bs/USD  | Credito directo al cliente (fiado)
Mixto                 | Ambas   | Combinacion de varios metodos

15. MODULOS DEL SISTEMA
=============================================================

PUNTO DE VENTA (POS)
  - Carrito de compras con busqueda por nombre o codigo de barras
  - Metodos de pago multiples (efectivo, transferencia, Zelle, etc.)
  - Pago mixto (dividir entre varios metodos)
  - Credito directo (fiado) con limite por cliente
  - Calculo automatico de vuelto
  - Impresion de ticket termico
  - Atajos de teclado: F4, F6, F7, F9

DASHBOARD
  - Resumen del dia: ventas, devoluciones, neto
  - Graficos de ventas por metodo de pago
  - Resumen para arqueo con desglose explicito
  - Ultimas ventas del dia

PRODUCTOS
  - CRUD completo de productos
  - Categorias organizadas
  - Busqueda y filtros
  - Alertas de stock bajo
  - Importacion/exportacion CSV
  - Impresion de codigos de barras

CLIENTES
  - Registro de clientes con datos fiscales
  - Limites de credito individuales
  - Historial de compras por cliente
  - Busqueda por nombre, CI/RIF, telefono

CIERRE DE CAJA
  - Pre-cierres (al cambiar turno/vendedor)
  - Cierre final del dia
  - Desglose por metodo de pago
  - Desglose por canal: Efectivo Bs, Efectivo $, Bs Electronicos, Divisas Digitales
  - Detalle de referencias (transferencias, pago movil, Zelle, USDT)
  - Desglose por rol (admin, vendedor, cajero)
  - Impresion del cierre
  - Historial de cierres

REPORTES
  - Ventas por periodo (dia, semana, mes, rango)
  - Desglose por metodo de pago
  - Cuentas por cobrar (creditos pendientes)
  - Resumen para arqueo
  - Exportacion CSV
  - Impresion

CREDITOS (CxC)
  - Lista de clientes con deuda
  - Ventas a credito por cliente
  - Registro de abonos parciales
  - Alertas de creditos vencidos

DEVOLUCIONES
  - Registro de devoluciones
  - Desglose del motivo
  - Afectacion en reportes y cierres

PROVEEDORES Y COMPRAS
  - Registro de proveedores
  - Registro de compras (ordenes)
  - Control de inventario por compras

USUARIOS Y ROLES
  - Creacion de usuarios con contrasena
  - Roles: Administrador, Vendedor, Cajero
  - Permisos por rol
  - Control de acceso a modulos

CONFIGURACION
  - Datos de la tienda (nombre, RIF, direccion)
  - Tasa BCV (manual o automatica)
  - Impresora termica (agente ESC/POS)
  - Metodos de pago habilitados
  - Facturacion (numero sequential)

LICENCIA
  - Plan BASICA (gratuito): POS basico
  - Plan BASICA+: Cierre de caja + creditos
  - Plan PROFESIONAL: Todos los modulos
  - Validez de la licencia

RESPALDOS
  - Respaldo manual de base de datos
  - Auto-respaldo programado
  - Descarga del respaldo
